# Px8S2Control

Bowers & Wilkins **Px8 S2** 헤드폰의 노이즈캔슬링(ANC) 모드를 아이폰에서 버튼 하나로 바꾸는 비공식 iOS 앱이에요.
B&W Music 앱을 열지 않고 **단축어, 액션 버튼, 제어 센터, 홈 화면 위젯**에서 모드를 바꿀 수 있어요.

> **B&W와 관련 없는 비공식 오픈소스 프로젝트예요.** 헤드폰이 B&W 앱과 주고받는 블루투스(BLE) 통신을 분석해서 만들었어요.
> 펌웨어 업데이트로 동작이 바뀔 수 있고, **Px8 S2에서만 확인**했어요. 사용에 따른 책임은 사용자에게 있어요.

## 기능

- 모드 3가지: **노이즈캔슬링 / 주변음 허용 / 끄기**
- **단축어 액션 "헤드폰 연결 / ANC 순환"**
  - 헤드폰이 이 기기에 연결돼 있지 않으면 **연결만** 해요.
  - 연결돼 있으면 고른 모드(2~3개)를 **순서대로 순환**해요.
- 헤드폰이 다른 기기(맥, 아이패드 등)에 붙어 있어도 **이 기기로 연결**해 오는 버튼
- 홈 화면 위젯: 고정 버튼 위젯, 보여줄 모드를 고르는 위젯

## 설치 (사이드로딩)

App Store에는 올라가 있지 않아요. [Releases](../../releases)의 서명 안 된 `Px8S2Control.ipa`를 직접 서명해서 설치해요.

1. Releases에서 `Px8S2Control.ipa`를 받아요.
2. AltStore, Sideloadly, Feather 같은 도구로 **본인 Apple ID(또는 개발자 인증서)로 서명해서 설치**해요.
3. 설치가 끝나면 아래 [처음 설정](#처음-설정)을 따라 하세요.

서명할 때 알아둘 점이에요.

- **번들 ID는 바꾸지 않는 걸 권해요.** 앱(`com.MACHU.Px8S2Control`)과 위젯(`com.MACHU.Px8S2Control.Widgets`)의 번들 ID는 앞부분이 같아야 해요. 도구에 번들 ID를 바꾸는 옵션이 있다면 끄거나, 바꾸더라도 위젯 ID가 앱 ID 아래에 붙도록 같이 바꾸세요.
- **무료 Apple ID**로 설치하면 7일마다 다시 서명해야 하고, 앱 개수 제한이 있어요. 위젯 익스텐션도 앱 ID를 하나 더 써요.
- **App Group**(앱과 위젯이 설정을 공유하는 권한)은 서명 방식에 따라 붙지 않을 수 있어요. 안 붙어도 모드 전환은 동작하고, 위젯에서 "마지막으로 보낸 모드" 강조만 안 바뀌어요.

## 처음 설정

처음 한 번만 하면 돼요. 5분이면 끝나요.

### 1. 헤드폰을 아이폰에 연결해요

설정 → 블루투스에서 **Px8 S2**를 평소처럼 페어링하고 연결해요. 이 앱이 따로 페어링을 요구하지는 않아요.

### 2. B&W Music 앱을 종료해요

B&W Music 앱이 헤드폰과 연결을 잡고 있으면 이 앱과 겹칠 수 있어요. 앱 전환 화면에서 B&W Music 앱을 위로 밀어 **완전히 종료**하세요. (설치돼 있는 건 괜찮아요.)

### 3. 설치한 앱을 신뢰하고 개발자 모드를 켜요

사이드로딩한 앱은 처음 실행 전에 아래 설정이 필요할 수 있어요. 이미 되어 있으면 건너뛰세요. (메뉴 이름은 iOS 버전에 따라 조금 달라요.)

- **개발자 모드**: 설정 → 개인정보 보호 및 보안 → 개발자 모드를 켜고 재시작해요.
- **앱 신뢰**: 설정 → 일반 → VPN 및 기기 관리에서 설치에 쓴 인증서를 신뢰해요.

### 4. 앱을 열고 모드를 하나 눌러 봐요

1. **Px8S2Control**을 열어요.
2. **소리 모드** 중 하나(예: 주변음 허용)를 눌러요.
3. 블루투스 권한 팝업이 뜨면 **허용**을 눌러요.
4. 헤드폰의 모드가 바뀌고 "…(으)로 바꿨어요"가 나오면 성공이에요.

권한을 실수로 거부했다면 설정 → Px8S2Control → **블루투스**를 켜 주세요.

### 5. (필요할 때만) 이 기기의 슬롯을 확인해요

헤드폰은 페어링한 기기를 목록(슬롯)으로 저장해요. 앱은 "이 기기에 헤드폰 연결"을 보낼 때 **이 기기가 어느 항목인지** 알아야 해요. 보통 자동으로 찾아요.

- 모드 전환만 쓴다면 신경 쓰지 않아도 돼요.
- 연결 버튼이 엉뚱한 기기로 연결하면, 앱의 **설정**에서 직접 골라요. ([설정 화면](#설정))

## 단축어 만들기

이 앱의 핵심 기능이에요. 한 번 만들어 두면 액션 버튼, 제어 센터, Siri 어디서든 쓸 수 있어요.

### 모드를 돌아가며 바꾸는 단축어 (권장)

1. **단축어** 앱을 열고 오른쪽 위 **+** 를 눌러요.
2. **액션 추가**를 누르고 검색창에 `Px8S2Control`(또는 `ANC`)을 입력해요.
3. **헤드폰 연결 / ANC 순환**을 눌러 추가해요. 화면에 `[노이즈캔슬링, 주변음 허용] 순환`처럼 보여요.
4. 파란 모드 목록을 눌러 **순환할 모드**를 골라요.
   - **2개 이상**을 골라야 해요. (예: 노이즈캔슬링 + 주변음 허용, 또는 세 가지 모두)
   - 1개만 고르면 "서로 다른 2개 이상 선택해 주세요"라는 오류가 나와요.
5. 위쪽 이름을 눌러 이름을 정하고(예: `ANC 전환`) **완료**를 눌러요.

이 단축어를 실행할 때의 동작이에요.

| 상태 | 동작 |
|---|---|
| 헤드폰이 이 기기에 연결돼 있지 않음 | **연결만** 해요. 모드는 바꾸지 않아요. |
| 연결돼 있고 현재 모드가 목록에 있음 | 목록에서 **다음 모드**로 바꿔요. 마지막 다음은 처음으로 돌아가요. |
| 연결돼 있고 현재 모드가 목록에 없음 | 목록의 **첫 번째 모드**로 바꿔요. |

실행이 끝나면 "주변음 허용(으)로 전환했어요", "헤드폰을 연결했어요" 같은 안내가 떠요.

### 모드를 바로 지정하는 단축어

1. 새 단축어에서 액션 검색으로 **ANC 모드 변경**을 추가해요.
2. 파란 모드 이름을 눌러 **노이즈캔슬링 / 주변음 허용 / 끄기** 중 하나를 골라요.
3. 모드마다 하나씩 만들어 두면 Siri나 위젯 대신 각각 따로 쓸 수 있어요.

### Siri

단축어 이름을 말하면 돼요. 앱이 기본으로 제공하는 문구도 있어요.

- "Px8S2Control 전환"
- "Px8S2Control 노이즈캔슬링"
- "Px8S2Control 주변음 허용"
- "Px8S2Control 끄기"

## 제어 센터 · 액션 버튼 · 잠금 화면에 넣기

위에서 만든 단축어를 다음 위치에 지정해서 쓰세요.

### 제어 센터

앱이 직접 제공하는 제어 센터 컨트롤은 없어요. 대신 시스템의 **"단축어" 컨트롤**에 위 단축어를 지정해요. (제어 센터 컨트롤의 인텐트는 위젯 익스텐션 안에서 실행되는데, 거기서는 블루투스를 쓸 수 없어서 동작하지 않아요.)

1. 제어 센터를 열고 왼쪽 위 **+** 를 누르거나, 빈 곳을 길게 눌러 **컨트롤 추가**를 눌러요.
2. **단축어** 컨트롤을 찾아 추가해요.
3. 추가된 컨트롤에서 **선택**(또는 컨트롤을 길게 눌러 설정)을 눌러 위에서 만든 단축어를 골라요.
4. 크기를 원하는 대로 바꾸고 완료해요.

### 액션 버튼 (iPhone 15 Pro 이상)

설정 → 액션 버튼 → **단축어**로 넘기고, 위 단축어를 선택해요. 버튼을 길게 누를 때마다 모드가 돌아가요.

### 잠금 화면

잠금 화면을 길게 누르고 **사용자화** → 잠금 화면에서 컨트롤 자리를 눌러 **단축어** 컨트롤을 추가하고 단축어를 골라요.

### 뒷면 탭

설정 → 손쉬운 사용 → 터치 → **뒷면 탭**에서 두 번 탭이나 세 번 탭에 위 단축어를 지정할 수 있어요.

## 홈 화면 위젯 (실험적)

설치 방식에 따라 위젯 버튼이 동작하지 않을 수 있어요. 그럴 땐 위의 단축어를 쓰세요.

1. 홈 화면의 빈 곳을 길게 눌러 편집 모드로 들어가고 **+** 를 눌러요.
2. **Px8S2Control**을 찾아요. 위젯이 2종류 있고 둘 다 **중간 크기**예요.

| 위젯 | 설명 |
|---|---|
| PX8 ANC (고정) | 끄기 / 노이즈캔슬링 / 주변음 허용 버튼 3개가 모두 나와요. |
| PX8 ANC (모드 선택) | 보여줄 모드를 골라요. |

3. **모드 선택** 위젯은 위젯을 길게 눌러 **위젯 편집**에서 **표시할 모드**를 골라요.
4. 마지막으로 보낸 모드는 버튼이 진하게 보여요. (App Group이 붙지 않은 설치에서는 이 강조가 바뀌지 않아요.)

## 앱 화면 설명

### 메인

- **소리 모드**: 노이즈캔슬링 / 주변음 허용 / 끄기. 누르면 바로 헤드폰이 바뀌어요. 체크 표시는 이 앱에서 **마지막으로 보낸 모드**예요. (헤드폰 버튼이나 B&W 앱으로 바꾼 건 반영되지 않을 수 있어요.)
- **이 기기에 헤드폰 연결**: 헤드폰이 다른 기기에 붙어 있을 때 이 기기로 가져와요. 이미 연결돼 있으면 "이미 연결돼 있어요"라고 알려줘요.
- 동작 중에는 로딩이 보이고, 실패하면 이유를 알려주는 창이 떠요.

### 설정

**이 기기는 헤드폰의 어느 항목인가요?**

- **헤드폰의 기기 목록 읽기**: 헤드폰에 저장된 기기 이름이 나열돼요. "지금 연결됨"이 붙은 항목은 현재 헤드폰이 붙어 있는 기기예요.
- 항목을 눌러 **이 기기에 해당하는 항목**을 직접 골라요. 체크 표시가 현재 선택이에요.
- 맨 위 안내문에서 현재 상태를 볼 수 있어요: "자동 감지", "직접 선택", "아직 감지 전".
- **자동 감지로 되돌리기**: 직접 고른 값을 지워요. 다음에 연결할 때 기기 종류(아이폰/아이패드)와 이름으로 다시 찾아요.

> iOS는 앱에 기기 이름을 숨기고 그냥 "iPhone"/"iPad"로만 알려줘요. 그래서 이름이 "iPhone"/"iPad"로 시작하는 항목을 고르는 방식이에요. 같은 종류 기기가 여러 대 페어링돼 있으면 엉뚱한 항목이 잡힐 수 있으니, 그땐 직접 고르세요.

### 단축어·위젯 사용법

이 README의 단축어 / 제어 센터 / 위젯 안내를 앱 안에서 볼 수 있어요.

### 정보

버전, 확인된 모델, 알아둘 점(비공식 앱, 펌웨어 변경 가능성), 개인정보 안내가 있어요. 이 앱은 블루투스로 헤드폰과만 통신하고 서버로 보내는 정보는 없어요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 헤드폰을 찾지 못해요 | 헤드폰이 아이폰에 블루투스로 연결돼 있는지 확인하고, **B&W Music 앱을 완전히 종료**하세요. 설정 → 블루투스가 켜져 있는지도 보세요. |
| "블루투스 권한이 없어요" | 설정 → Px8S2Control → **블루투스**를 켜세요. |
| 모드가 안 바뀌어요 | 헤드폰 전원과 연결을 확인하고 앱의 모드 버튼으로 먼저 시험해 보세요. 앱에서는 되는데 단축어에서 안 되면 단축어에 액션이 제대로 들어 있는지 보세요. |
| 단축어를 눌러도 "연결"만 돼요 | 이 기기에 연결돼 있지 않다고 판단한 거예요. 한 번 더 실행하면 모드가 바뀌어요. 계속 그러면 **설정**에서 이 기기에 해당하는 항목을 직접 고르세요. |
| 엉뚱한 기기로 연결돼요 | **설정**에서 이 기기에 해당하는 항목을 직접 고르세요. |
| 첫 순환이 예상과 반대로 가요 | 앱은 헤드폰의 현재 모드를 직접 읽지 못해서 마지막으로 보낸 모드를 기준으로 해요. 헤드폰 버튼이나 B&W 앱으로 바꿨다면 한 번 어긋날 수 있어요. 이후엔 헤드폰이 알려주는 상태로 맞춰져요. |
| 단축어에서 "서로 다른 2개 이상 선택해 주세요" | 순환할 모드를 2개 이상 고르세요. |
| 위젯 버튼이 안 눌려요 | 위젯은 실험적이에요. 단축어를 쓰세요. |
| 키보드를 올릴 때마다 헤드폰에서 삑 소리가 나요 | 이 앱과 무관해요. iOS의 **키보드 사운드**가 무음 오디오 스트림을 열 때 헤드폰이 소리를 내는 걸로 보여요. 설정 → 사운드 및 햅틱 → 키보드 피드백에서 **소리**를 끄면 사라져요. |
| 7일 뒤 앱이 안 열려요 | 무료 Apple ID로 설치한 앱은 7일마다 다시 서명해야 해요. 같은 번들 ID로 다시 설치하면 돼요. |

## 직접 빌드

필요한 것: Xcode, [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`)

```bash
xcodegen generate
open PX8Control.xcodeproj
```

서명하려면 `project.yml`에서 아래 값을 본인 것으로 바꾸세요.

- `DEVELOPMENT_TEAM`
- 번들 ID: `com.MACHU.Px8S2Control` (위젯은 `….Widgets`)
- App Group: `group.com.MACHU.Px8S2Control` (`Shared/PX8Config.swift`의 `appGroup`도 같이)

서명 없이 IPA만 만들려면:

```bash
xcodebuild -project PX8Control.xcodeproj -scheme PX8Control -configuration Release \
  -sdk iphoneos -destination 'generic/platform=iOS' -derivedDataPath build \
  CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO build
mkdir Payload && cp -R build/Build/Products/Release-iphoneos/Px8S2Control.app Payload/
```

## 어떻게 동작하나요

헤드폰이 BLE로 받는 짧은 명령을 그대로 보내요. 분석한 내용은 [PROTOCOL.md](PROTOCOL.md)에 정리해 뒀어요.

## 한계

- Px8 S2에서만 확인했어요. 같은 프로토콜을 쓰는 다른 B&W 헤드폰은 동작할 수도 있지만 확인하지 않았어요.
- 위젯과 단축어 같은 시스템 진입점은 iOS 버전과 설치 방식에 영향을 받아요. iOS 18 이상에서 개발했어요.
- 이 앱은 헤드폰의 현재 모드를 직접 읽지 못해요(조회 명령을 찾지 못했어요). 마지막으로 보낸 모드와 헤드폰이 알려주는 상태 이벤트로 추적해요.
- 앱이 직접 제공하는 제어 센터 컨트롤은 없어요. 시스템 "단축어" 컨트롤을 쓰세요.
